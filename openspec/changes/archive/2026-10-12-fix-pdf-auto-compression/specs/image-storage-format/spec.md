## MODIFIED Requirements

### Requirement: Stored images embedded without re-encode in PDF save

When saving a PDF, an unmodified imported image whose resolved compression is
JPEG SHALL be embedded verbatim; images that scantpaper generated by scanning
or editing, and images whose resolved compression differs from their stored
encoding, SHALL be encoded according to the selected output compression.

#### Scenario: Imported JPEG saved with automatic compression

- **WHEN** saving a PDF with automatic compression for a page imported verbatim from a JPEG file and not modified since
- **THEN** the stored JPEG bytes SHALL be written to the PDF without re-encoding
- **AND** the PDF output SHALL embed the stored image stream natively

#### Scenario: Imported PNG saved with automatic compression

- **WHEN** saving a PDF with automatic compression for a page imported verbatim from a PNG file and not modified since
- **THEN** the page SHALL be re-encoded according to the automatic compression selection rather than embedded verbatim

#### Scenario: Generated image saved with automatic compression

- **WHEN** saving a PDF with automatic compression for a scanned or edited page
- **THEN** the image SHALL be encoded according to the automatic compression selection rather than embedded verbatim

#### Scenario: PDF save with downsampling

- **WHEN** saving a PDF with downsampling enabled
- **THEN** the page SHALL be re-encoded at the target resolution regardless of provenance
